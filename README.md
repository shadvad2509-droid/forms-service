# \# Forms Service

# 

# Сервис форм для карьерной платформы студентов. Менеджер создаёт форму в админке, получает публичную ссылку, студент заполняет, менеджер видит ответы.

# 

# \## Стек

# \- Node.js 20+

# \- Express

# \- EJS (шаблоны)

# \- SQLite (встроенная БД)

# \- Tailwind CSS (через CDN)

# 

# \## Запуск

# 

# ```bash

# npm install

# npm start
