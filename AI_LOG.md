# Лог работы с AI

## Задача
Сервис форм на Node.js для карьерной платформы: админка для создания форм, публичная ссылка для заполнения, просмотр ответов.

## Использованные AI-инструменты
- Claude (через веб-интерфейс) — архитектура, код, шаблоны.

## Как работал

### 1. Архитектура
- Спросил у AI, как лучше спроектировать сервис с учётом требований (Node.js, SQLite, без внешних БД).
- AI предложил стек: Express + EJS + SQLite.
- Проверил, что SQLite встроен в Node.js (через npm-пакет `sqlite3`, не требует установки сервера).

### 2. Код
- AI написал `server.js` с роутами: `/admin`, `/admin/create`, `/f/:token`, `/admin/responses/:id`.
- AI написал `db.js` — инициализацию SQLite с таблицами `forms` и `responses`.
- AI написал EJS-шаблоны для админки, публичной формы и просмотра ответов.
- Проверил каждую часть: запускал, смотрел в браузере, проверял эндпоинты.

### 3. Что проверил вручную
- `npm install` — устанавливает зависимости.
- `npm start` — запускает сервер на `http://localhost:3000`.
- `$env:PORT=4000; npm start` — проверяет, что порт настраивается через переменную окружения.
- Создание формы с полями «Имя, Email, Телефон» — работает.
- Публичная ссылка `/f/:token` — открывается.
- Отправка ответа — сохраняется в БД.
- Просмотр ответов в админке — отображается.
- Перезапуск сервера — данные сохраняются в `data.db`.

- Проверил, что `package.json` содержит все зависимости и правильный скрипт `start`.
- Убедился, что `PORT` читается через `process.env.PORT || 3000`.
